*======================================================================*
* DYNPRO SCREEN DEFINITION: 0100 (QC Physical Sample Collection Cockpit)
* Program: SAPMZPPLIS_NN / ZPPLIS_NN
* Business Logic: Root N + 1 Sample Calculation & HU/SU Barcode Verification
* Screen Type: Normal (75 cols x 24 lines, WebGUI / ITSmobile enabled)
*======================================================================*

----------------------------------------------------------------------
1. FLOW LOGIC (Screen 0100)
----------------------------------------------------------------------
PROCESS BEFORE OUTPUT.
  MODULE status_0100.

PROCESS AFTER INPUT.
  MODULE user_command_0100.

----------------------------------------------------------------------
2. SCREEN PF-STATUS & GUI TITLE DEFINITIONS
----------------------------------------------------------------------
GUI Status : STATUS_0100
Titlebar   : TITLE_0100 ("QC Sample Collection - Root N + 1 Formula")

Function Keys / Pushbuttons:
  ENTER (Fcode: ENTR) -> Search Lot / Validate & Process Scanned HU
  F2    (Fcode: EXEC) -> Execute / Load Lot
  F3    (Fcode: EXIT) -> Exit Program
  F4    (Fcode: CLEA) -> Clear Inputs / Unlock Lot
  F7    (Fcode: PRNT) -> Reprint Sample Label
  F8    (Fcode: DEMO) -> Load Demo Lot (N=10 -> Target=5)
  F12   (Fcode: CANC) -> Cancel
