*======================================================================*
* DYNPRO SCREEN DEFINITION: 0200 (Sample Collection & Verification Screen)
* Program: SAPMZPPLIS_NN / ZPPLIS_NN
* Screen Type: Normal (60 cols x 22 lines, WebGUI / ITSmobile enabled)
* Maintenance Transaction: SE51 / ADT / ZCREATE_TCODE_ZPPLIS_NN
*======================================================================*

----------------------------------------------------------------------
1. FLOW LOGIC (Screen 0200)
----------------------------------------------------------------------
PROCESS BEFORE OUTPUT.
  MODULE status_0200.

PROCESS AFTER INPUT.
  MODULE user_command_0200.

----------------------------------------------------------------------
2. SCREEN PF-STATUS & GUI TITLE DEFINITIONS
----------------------------------------------------------------------
GUI Status : STATUS_0200
Titlebar   : TITLE_0200 ("Physical Sample Collection & Verification")

Function Keys / Pushbuttons:
  ENTER (Fcode: CONF) -> Confirm Sample & Verify
  F3    (Fcode: BACK) -> Back to Screen 0100
  F5    (Fcode: NEXT) -> Next Sample Item
  F6    (Fcode: PREV) -> Previous Sample Item
  F7    (Fcode: PRNT) -> Print Barcode Label (ZPL)
  F8    (Fcode: REST) -> Reset Sample Status (CRTD)
  F12   (Fcode: CANC) -> Cancel
