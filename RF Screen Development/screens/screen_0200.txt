* Program: SAPMZRF_RES_WM_TRANSFER / ZRF_RES_WM_TRANSFER
* Screen Type: Normal (RF Terminal Layout 16 lines x 20/40 cols)
* Maintenance Transaction: SE51 / ADT
*======================================================================*

----------------------------------------------------------------------
1. FLOW LOGIC (Screen 0200)
----------------------------------------------------------------------
PROCESS BEFORE OUTPUT.
  MODULE status_0200.

PROCESS AFTER INPUT.
  MODULE user_command_0200.

----------------------------------------------------------------------
2. SCREEN PF-STATUS & GUI TITLE DEFINITIONS
----------------------------------------------------------------------
GUI Status : STATUS_0200
Titlebar   : TITLE_0200 ("Scan HU & Execute Transfer")

Function Keys / Pushbuttons:
  ENTER (Fcode: ENTR) -> Validate Scanned HU
  F1    (Fcode: POST) -> Single-Click Execute Posting (IM + WM)
  F2    (Fcode: NEXT) -> Next Open Item
  F3    (Fcode: BACK) -> Back to Selection Screen 0100
  F4    (Fcode: CLEA) -> Clear Scanned HU Fields
  F6    (Fcode: SERN) -> Show Serial Numbers in HU
  F7    (Fcode: BINS) -> Show Stock Storage Bins
