* Maintenance Transaction: SE51 / ADT

----------------------------------------------------------------------
1. FLOW LOGIC (Screen 0100)
----------------------------------------------------------------------
PROCESS BEFORE OUTPUT.
  MODULE status_0100.

PROCESS AFTER INPUT.
  MODULE user_command_0100.

----------------------------------------------------------------------
2. SCREEN PF-STATUS & GUI TITLE DEFINITIONS
----------------------------------------------------------------------
GUI Status : STATUS_0100
Titlebar   : TITLE_0100 ("RF Reservation -> WM Transfer")

Function Keys / Pushbuttons:
  ENTER (Fcode: ENTR) -> Validate & Enter
  F3    (Fcode: BACK) -> Back / Exit
  F4    (Fcode: CLEA) -> Clear Inputs
  F12   (Fcode: CANC) -> Cancel
